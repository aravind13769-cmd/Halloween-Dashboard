# 🎃 Halloween Visitor Analysis

## 📊 Project Overview

The **Halloween Visitor Analysis** project is a data visualization and analysis dashboard designed to understand visitor patterns during Halloween events.

The dashboard analyzes visitor data from **2008 to 2014** and highlights important insights such as total visitors, peak visitor year, highest and lowest visitor counts, yearly trends, variations, and forecasting.

The visualization provides an easy-to-understand overview of how visitor numbers changed over the years.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze yearly Halloween visitor trends.
- Identify the year with the highest number of visitors.
- Identify the year with the lowest number of visitors.
- Calculate the total number of visitors.
- Compare visitor strength across different years.
- Understand year-by-year variations.
- Visualize historical visitor performance.
- Use forecasting to understand potential future visitor trends.
- Present insights through an attractive and easy-to-understand dashboard.

---

## 📅 Dataset

The analysis uses Halloween visitor data covering the period:

**2008 – 2014**

The visitor count represents the total number of visitors during the specified period.

### Key Data Points

| Year | Visitors |
|------|----------|
| 2008 | 492 |
| 2009 | 542 |
| 2010 | 726 |
| 2011 | 869 |
| 2012 | 673 |
| 2013 | 391 |
| 2014 | 454 |

## 📈 Dashboard Highlights

### 👥 Total Visitors
The total number of visitors recorded during the analyzed period is:

**4,147 Visitors**

### 🏆 Peak Year
The highest visitor count was recorded in:

**2011 – 869 Visitors**

### 📉 Lowest Visitor Year
The lowest visitor count was recorded in:

**2013 – 391 Visitors**

### 📊 Visitor Trend

The visitor trend shows:

- A gradual increase from **2008 to 2011**
- The highest point in **2011**
- A decline from **2011 to 2013**
- A slight recovery in **2014**

## 🔍 Key Insights

Based on the analysis:

1. **2011 recorded the highest number of visitors**, with 869 visitors.
2. Visitor numbers increased consistently between **2008 and 2011**.
3. The period from **2011 to 2013 experienced a significant decline** in visitors.
4. **2013 had the lowest visitor count**, with 391 visitors.
5. Visitor numbers showed a **small recovery in 2014**, increasing to 454.
6. The overall trend indicates that visitor activity reached its peak in 2011 before declining in subsequent years.
